# HW2 Character build - Pikmin Bloom
This repo contains the submission for MMED-1054 Homework #2: Character Build by Jin Cheon.  
It features a character-themed website based on *Pikmin Bloom*, a mobile game developed by Nintendo.  
The site introduces various characters from the game in a playful and engaging format.

## Installation 💻
No installation required, simply download the zip file and extract.

## Usage
Open index.html in your choice browser and enjoy my work.
